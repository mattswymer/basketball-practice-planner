QUICK GUIDE

Using the planner

Build a practice

Search or filter the activity bank. Use + to add a drill. Select a scheduled activity to edit its details. Use the arrows to reorder it, or drag it on a desktop.

Run stations concurrently

A station rotation is one timed block containing several activities that run at the same time. It counts once toward the practice duration, not once per station.

Fit the gym window

Set the start and end times, then select Fit to allotted time. The planner distributes whole minutes proportionally and makes the total match the available window.

Run live practice

Start live practice to show the current activity, coaching cues, equipment, and countdown. Pause, move forward or backward, or end the session.

Save and move between computers

The app saves automatically in this browser. Export a JSON backup to move a practice or activity bank to another device. Printing opens a clean practice handout.
